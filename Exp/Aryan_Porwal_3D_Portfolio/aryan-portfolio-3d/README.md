# Aryan Porwal — 3D Dynamic Portfolio

Open `index.html` in a modern browser.

Included:
- Responsive one-page portfolio
- CSS 3D portrait tilt / depth layers
- Animated scan line, floating 3D chips and glass quote card
- Dynamic cursor glow
- Scroll reveal animations
- Experience timeline
- Skills, tools, education and certifications
- Mobile responsive layout
- Original uploaded portfolio image used as the hero visual

To publish: upload the folder to GitHub Pages, Netlify, Vercel, or any static web host.

ARYAN PORWAL — FINAL PREMIUM PORTFOLIO

Files:
- index.html
- styles.css
- script.js
- assets/aryan-portrait.jpg
- assets/profile-poster.png

Open index.html in a browser.
The site is dependency-free at runtime apart from Google Fonts; the 3D and particle effects are implemented in vanilla JavaScript/CSS.

To publish with GitHub Pages:
1. Create a GitHub repo.
2. Upload all files preserving the assets folder.
3. Enable Settings -> Pages -> Deploy from branch.

To customize text, edit index.html and the data arrays at the top of script.js.
